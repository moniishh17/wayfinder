# Transit data notice

The MTC route and stop index in `chennai-transit.json` is derived from the Chennai GTFS feed published by [UngalSoththu / Ithu Ungal Soththu](https://github.com/ungalsoththu/ChennaiGTFS). The source repository identifies its data as ODbL-1.0 and requires attribution and share-alike for database derivatives. Attribution: **UngalSoththu / Ithu Ungal Soththu**.

The source feed's `feed_info.txt` states a validity end date of 2025-12-31. Treat bus route patterns as historical references until a newer valid feed is confirmed. This notice covers the derived transit database, not the application code or other third-party assets.
